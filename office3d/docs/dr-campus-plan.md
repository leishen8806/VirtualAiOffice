# DR 仓配服务中心园区规划（S2-0c）

> 状态：规划完成，尚未施工。全部名称、分区、指标和动画均为**示意 / 模拟**，不代表真实地址、客户、商户、订单、库存或面积。北为 `-z`；坐标单位为游戏米，全部落在 `0.5m` 网格。

## 1. 结论与边界

推荐把仓配园区迁到西路另一侧：园区外框 `x=-174…-72,z=-26…42`，面积 `6936㎡`。它与西路东侧的办公室、DR 广场和 O1 规划完全分离；沿西路预留 `8m` 缓冲带。园区是一座开放式的**单体仓配服务中心**，不是多栋铁皮房拼接。

本卡不施工：不改场景、人物目的地、`foyerTrip / plazaTrip / 小橘` 路线、`PLAZA`、O1 的 `ENVELOPE`，也不读写 Paperclip。西路穿越只做视觉斑马线和地面导视；人物仍不会前往园区。

### 参考依据与比例

概念图决定空间关系：北侧收货、东侧发货、中央货架和拣选包装、南侧接待展示、东西两侧调度和维护。建材城平面图只借鉴 W1/W2/W3、A/B/C 带、加工/设计/运营/服务等业态与三类动线，**不转用真实租户、地址或经营面积**。

现有 S2-2 外壳的 `28×12=336㎡` 与建材城图的 W1 标注 `4015㎡` 对照，得到概念换算：`1 游戏㎡ ≈ 11.95 示意实际㎡`，线性比例约 `1:3.46`。这是构图标尺，不是工程测量。

| 方案 | 园区外框 | 游戏面积 | 示意实际面积 | 取舍 |
|---|---|---:|---:|---|
| 紧凑 | `x=-154…-72,z=-18…38` | 4592㎡ | 约 5.49 万㎡ | 可容纳核心中心，前广场、停车和内环余量较小 |
| **推荐：完整园区** | **`x=-174…-72,z=-26…42`** | **6936㎡** | **约 8.29 万㎡** | 保留大型单体中心、四月台、东向发货、前广场及后续绿化缓冲 |

## 4. 动画、性能与画质

| 物件 | 高 / 低档 | 实例化或合并策略 | 新增 calls / 三角形预算 |
|---|---|---|---:|
| 高位货架和货箱 | 全部货架 / 降为 2 排与少量箱 | `InstancedMesh`，共用几何材质 | 2 / ≤18k |
| 传送带和货箱 | 2 条确定性循环 / 静态 | 传送带合并，货箱实例化 | 1 / ≤5k |
| 叉车 | 2 辆循环 / 1 辆静态 | 单根动态组；固定相位，不读数据 | 1 / ≤4k |
| 卡车 | 2 静 1 动 / 2 静 | 共享车体几何、一个动态根 | 2 / ≤8k |
| 前广场、水景、门牌 | 可见 / 简化无水面动画 | 静态按材质合并 | 3 / ≤12k |
| 调度中控屏 | “模拟”静态/低频 Canvas | 最大 1024×512，仅内容变更重绘 | 1 / ≤1k |
| **合计** | **≤12 calls / ≤48k** | **低档 ≤5 calls / ≤15k** | 新增光源 `0` |

所有动画必须是固定种子 + 本地时间片的确定性展示，独立总开关默认关闭；低档隐藏或静态化动态物件。静态根配合 `quality.js` 合并，叉车/卡车/传送带才标记动态。调度屏只画“模拟调度画面”，没有 Paperclip、真实订单或网络读取。
