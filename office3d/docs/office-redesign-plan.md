# O1 办公区重新规划 rev2：按概念效果图校准

日期：2026-10-21（Asia/Phnom_Penh）  
状态：**规划完成，尚未施工**。本文件只定义 `?layout=2` 的候选空间；不改变当前场景、服务、业务流程或 Paperclip 数据。

## 1. 本次修订结论

董事会效果图将南入口、圆形中庭、Ø7m 茶水吧台和北门放到同一条 `x=2` 中轴上。rev1 的吧台中心 `(-11,-1)`、东侧入口脊柱和不对称的 72×30 外框不再作为推荐方案。

推荐采用完整效果图外框：`x=-34…38,z=-18…16`，宽 `72m`、深 `34m`、面积 `2448㎡`。它关于入口轴线 `x=2` 对称，面积较当前 `1716㎡` 增加 `732㎡`（`+42.7%`）。这已超过“再扩大一点”的通常含义；北侧铺装、树/路灯、小地图和相机都要随 O3/O8 复核，不能把它说成小改动。

核心原则：空间和视觉中轴保持笔直；人物主路径到达中庭后沿圆形通行环分流，**不穿过吧台台体**。概念图表达的是视觉轴，不是允许人物直线穿模的路径。

### 已知事实

- 当前 `ENVELOPE` 是 `66×26=1716㎡`，有 9 个真实区域 id、25 个真实工位。
- 当前运行时人物碰撞半径为 `0.22m`，人与人的最小间距为 `0.52m`；现用椅子表面约 `0.54×0.52m`。
- `PLAZA` 固定为 `x=-10…14,z=16…30`；其内部中央圆、摊位、咖啡车、队列和等候座位不改。
- `corridorPath / officeExit / officeTrip / meetingTrip / loungeTrip / consumerTrip` 的签名与返回形状不能变。

### 未确认的事实

- rev2 还未渲染，更没有做 25 人或 37 人的真实路径压力测试。
- 文件规划检查只能验证坐标、净距和图连通性；不能代替墙体采样、实际桌椅网格碰撞或 T16b 的 200 种子压力测试。

## 6. 中庭、吧台、前厅与广场接缝

中庭中心与吧台中心均为 `(2,-1)`：

| 圈层 | 半径/范围 | 用途与净距 |
|---|---|---|
| 中央绿植 | `r≤0.9m` | 仅吧台中心装饰，不做行人目标 |
| 吧台碰撞环 | `r=3.5m` | Ø7m 吧台、10 个外圈吧凳；人物禁止穿入 |
| 内缓冲 | `r=3.5…4.7m` | 吧凳后退和服务位；不作为主通行带 |
| 弧形沙发区 | 西/东各 `r=4.7…6.0m`、避开南北门户 | 合并原 `LOUNGE_*`；每侧 3 席 |
| 通行环 | `r=6.0…8.0m` | 最窄 `2m`，分担人物绕行 |
| 南北门户 | `x=0…4`，北 `z=-9…-8`、南 `z=6…7` | 各 `4m` 宽，连接中轴与环路 |

吧台设置东、西两个 `1.5m` 服务缺口。南北中轴门户均达到 `4m`；吧台本体不是直线走廊的一部分，人员在门户进入环路后从东/西侧绕行。前台中心 `(2,14.5)`，宽 `5.5m`，其两侧各至少 `2m` 绕行；左服务吧台 `x=-14…-5,z=13…14.5`，右等候弧形沙发 `x=9…18,z=13…15.5`。南门洞 `x=-2…6,z=16`，标识“欢迎光临”，接触但不侵入广场。

圆形碰撞采用 12 个 30° AABB 段；东/西两段按 `1.5m` 缺口移除。每段包络比真实圆弧最多多出约 `0.12m`（12 段外包）；若低档改成 8 段，最大额外阻挡约 `0.27m`，仅在环路实测净宽仍不少于 `1.2m` 时允许。任何方案都不得以缩小 `0.52m` 人间净距换取空间。

北门为视觉门：`x=-1…5,z=-18`，以玻璃和门框呈现，v1 锁闭且不写入人物导航；原因是北侧外部环境尚无可验证碰撞/路径系统。待外部道路完成后，另卡开启。

| 南中轴 | `x=0…4,z=6…16`，4m | 前厅、南门到中庭南门户 |

| 南侧横廊 | `x=-34…38,z=5…7`，2m | 南侧房间门外通行 |
| 前厅横向余量 | 前台两侧各 ≥2m | 访客绕台、服务与等候分流 |

区域外框不得与任何已声明通道面积重叠。唯一白名单是“门洞贴边”：房门与走廊边界相接而不相交；中庭环路与南北门户相接而不相交。吧台碰撞段不得接触通行环内边界以外。检查脚本显式验证这些规则，`MUTATE=spine` 必须制造房间压住中轴并失败。

路径函数不改签名或返回形状，实施语义如下：

- `officeExit`：桌位后退 → 本区门洞内外点 → 对应北/南横廊。
- `corridorPath`：横廊 → 中庭门户 → 东/西通行环 → 目标横廊；跨前厅时绕中轴前台两侧。
- `officeTrip`：`officeExit` + 上述公共路径 + 目标门洞/椅后站位。
- `meetingTrip`：公共路径 + A/B 的门洞 + 会议桌外圈座位通道；A 为 8 席，B 为 6 席。
- `loungeTrip`：公共路径 + 对应东西沙发弧的入座点；不穿吧台和吧凳。
- `consumerTrip`：公共路径 + 前台侧绕行 + 前厅服务/等候或广场既有路线。

实施 O5 的最低验收：每个真实工位到前台、A/B 会议室、休闲座位和南出口的路线不得穿墙、穿桌椅或进入吧台 AABB；先跑 25 人，再加默认关闭的 12 个展示人做 T16b 200 固定种子。当前仅做规划图连通检查。
