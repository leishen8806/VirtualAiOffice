## 1. 结构：已一致
概念图的分区与 rev2 完全同构（同一设计语言的延伸）：北排自西向东「市场部（展示）→ 会议与决策 → 产品·工程·知识 → 客服部（展示）」，南排「售后部（展示）→ 运营·质量与安全 → 前厅接待区 / 中央茶水吧 → D.life 工坊 → 营销部（展示）」，中央圆形茶水吧岛（中心一棵大型景观树）+ 环形主通道，南侧前厅接待区 + DR 广场。四个角部展示单间 = rev2 的 `market / service / aftersales / marketing`。

## 3. 设计提示词里 rev2 / 现有实现**尚未覆盖**的内容（与尺寸无关，可直接采用）
- **材质与氛围：** 暖米色 / 浅米色主色调，融合玻璃、石材、浅橡木、绿植与柔和金属细节；整体"温暖、精致、通透、有秩序"。→ 对应 AS2-1 的贴图样板。
- **中央吧台：** 吧岛中心一棵大型景观树；吧台下沿有暖色 LED 灯带；沙发为蓝灰 / 青色织物。→ AS2-1 与 Trae 吧台后续（暖色灯带、青灰沙发配色）。
- **前厅与广场生活细节：** 前台与导视、餐车 / 小货亭（广场左右）、阳伞与露天座椅、路灯、成片花带与景观树、长椅。→ 生活线（O8 与广场相关卡）。
- **局部功能：** 创意讨论区、餐饮休憩角。→ 待董事会确认是否纳入。
- **禁止：** 不出现真实品牌 logo、商标、水印或具体公司名称（与现有"示意 / 模拟"标注规则一致）。

## 4. 底部四张室内特写（质量样板的目标画面）
1. **中央茶水吧岛**：圆形木质吧台 + 暖色灯带 + 中央大树 + 蓝灰沙发 + 吧凳。→ 办公区样板（AS2-1）第一目标。
2. **开放办公区**：白色桌面、深色显示器、桌间绿植花槽、地面浅木 / 石材。→ 办公区样板第二目标（邻近工位）。
3. **会议洽谈室**：长条浅木会议桌、深色座椅、玻璃隔断、暖色顶灯。→ 后续扩展。
4. **休闲会客区**：青绿色沙发、圆形小茶几、盆栽。→ 后续扩展。
