文档集中于 docs；本文件记录空间设计，运行中的样式与尺寸以源码为准。

- 用户指定：`E:\Dr.life+\historical`。
- 空间参考：`photo_7_2026-10-09_11-17-44.jpg` 的黑框玻璃隔断、完整围合、独立入口、暖金收边。

## 边界

- 玻璃为完整高度的静态隔断；门洞保持敞开，不含动态开关门。
- 无屋顶以便管理视角查看；并非施工图或建筑合规认证。
- 跨办公室经公共通道与门洞；不以穿墙代替可达性。
- 核验同时包含边界/门洞单测、实际页面加载、独立人物副本完整往返，以及桌面和窄屏截图。
- 人物头顶完整信息默认隐藏；点击人物仍通过现有人物卡查看姓名、岗位、模型和任务。区域标签与真实事件气泡保持原有远景隐藏规则。
- 休息区独立安排在左侧前廊（中心 x=-13、z=10.9），两张沙发侧向面对面，六个座位；大门前方为迎宾通道，不摆沙发、茶几和散椅。地面色块与标识区分功能区。
- 休息家具、座位、路径、猫的躲雨点和休息区镜头同步迁移；座位和路径统一使用 office-layout.js。
- 人物通行净距由 pedestrian-traffic.js 统一控制（中心至少0.52米），绕行不越过已有家具碰撞；休息区前廊独占通行，等候者留在原座位，离开前廊后放行下一人。
- travel 与事件共享3人行动上限；入座顺序为起身/行走/转正/落座，转正期间 sit=0，落座期间朝向锁定。该规则不等于衣料和四肢的完整网格碰撞。

## DR 园区全景仪表盘（2026-10-22）

- 独立页面 `dr-console.html` 以董事会 `DR智慧仓配中心全景仪表盘6.0.png` 为构图依据：顶栏、八张 KPI、全景园区、左导航、右上柬埔寨地图、右下入口画面、底部五列业务面板。
- 园区底板为该本地参考图的 JPEG 优化副本，通过 CSS 取景；标明“设计参考图 · 非实景”，监控缩略图标明非直播。底板不冒充可自由旋转的三维模型；动态数值与界面控件由 HTML/JS 渲染。
- 配色由独立页面的 CSS 变量持有：深蓝 `#041321/#082238`、描边 `#256487`、青蓝 `#49cfff`、金 `#efc675`；浅色使用同一组主题变量。办公区暖色主题不引用此页。
- 数据与 KPI 继续由 `dr-console-data.js` 的唯一模拟快照推导，城市和经纬度投影继续使用 `dr-cambodia-outline.js`，不将 W1/W2/W3 作为城市名。页内筛选不请求接口。
- 导航、状态按钮、园区热点用原生 button；流水选择沿用原生 select（接受系统弹层），时间统一金边；全局滚动条由本页 CSS 持有。设备、库存为有界小集合；流水表在自身面板内滚动。
- 1920 宽保留五列全景构图，1280 宽底部降为三列，390 宽纵向排列；全页无横向溢出。截图验收保存在对应上级备份目录，验收通过后清理。
- 模拟模式唯一可用；“实时/回放”禁用并提示未接入。页面隐藏或离开时停止时钟定时器，返回后恢复；无写操作、下载或外部接口请求。
