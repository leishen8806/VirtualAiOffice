## 要做的事
1. **处理脚本** `tools\texture-prep.mjs`（Node，**不新增 npm 依赖**；用无头 Chrome 的 `<canvas>` 做像素处理——Playwright 与 Chrome 在你的运行时里已有；脚本只是开发工具，不进入浏览器运行包）。同一输入同一输出（无随机、无时间戳写进图里）。功能：
   - 缩放到目标尺寸（平铺贴图取**中心正方形裁剪**后缩到 1024×1024；非平铺的保持比例，长边 ≤1024；门头底图 1024×256 左右）。
   - **平铺贴图无缝化**（标注「平铺」的：橡木、胡桃木、石材地面、织物、粉刷墙、混凝土地面、沥青、缠绕膜）：偏移半幅 + 重叠渐变混合消除接缝，并输出**处理前后接缝差对照**（沿用上面的度量：左右边缘差 vs 相邻列参考差，目标处理后 ≤ 参考差的 1.5 倍）。
   - **图集去黑底取 Alpha**（叶片图集、棕榈图集）：按亮度键控 + 2 px 收缩去毛边 + 边缘去色溢（把边缘像素颜色向内部均值靠拢）。若处理后仍可见亮绿毛边（你判断并在预览里 3×3 放大看），**如实写「需 GPT 重绘透明背景版」**，不要硬凑；这两张在本卡的验收里允许标为「待重绘」。
   - 输出格式：不透明的输出 **JPEG（质量 88）**，带 Alpha 的输出 PNG；颜色空间 sRGB；文件名去掉序号前缀（如 `office-oak-light.jpg`）。
2. **输出目录（两条线分开，放进 `office3d` 但默认页面不会请求）：**
   - 办公区：`office3d\assets\textures\office-v2\`
   - 仓配：`office3d\assets\textures\dr-campus\`
   - 原图保持在 `asset-intake\gpt-textures\` 不动（只读）。
3. **留档**：写入 `office3d\assets\third-party\MANIFEST.json`（与 AS1-2 共用该清单，**追加不覆盖**）：每张贴图一条记录——处理后文件名、对应原图文件名与 SHA-256、来源 = 「董事会在 ChatGPT 生成，2026-10-22，按 `GPT-texture-redraw-prompts.md` 的提示词；原提示词文本未逐张保存」、许可 = 「AI 生成，由董事会按其账号适用的 OpenAI 使用条款使用；无第三方许可」、产品线、尺寸、字节数、是否平铺、接缝差前后、处理说明。**不要编造提示词。**
4. **预览页** `texture-preview.html`（只请求本地静态资源，深浅主题都可读，控制台 0 错误）：两个标签「办公区」「仓配」，每张贴图显示原图缩略、处理后图、**3×3 平铺预览**（看接缝）、尺寸 / 字节 / 接缝差 / 是否带透明；Alpha 图叠在棋盘格背景上显示。
5. **测试**（`tests\texture-assets.test.mjs`）：目录里每个贴图文件都在 MANIFEST 里有记录且 SHA-256 与文件一致；办公区目录只含办公区条目、仓配目录只含仓配条目；每张 ≤1024 边长；单文件 ≤400 KB、单产品线合计 ≤3 MB；平铺贴图的接缝差在目标内（用脚本输出的度量文件断言，不重算像素）；`app.js` 与任何场景模块**未被改动**；默认页面零新增请求（路由快照）。全量 `node --test` 全过，不放宽任何断言。
