- 动手前先查项目里和 Paperclip 里已有的能力、组件与约定，能复用的不再造一套；不新增重复系统，不为「少写代码」破坏现有层次、接口与任务范围。
- **已批准的 3D、游戏化、交互、双主题、多公司、默认关闭与降级等要求是任务要求，不是可以自行删掉的「过度设计」。** 不确定某项要求能否简化时，先停下写明，由规划者向董事会确认。
- 不得削弱权限、幂等、状态校验、审计、证据绑定、故障隔离和必要测试；这些即使看起来重复，也可能承担不同边界的保护。
- 不得把模拟数据、动画进度或客户端状态当作真实业务结果；演示与真实必须在界面上清楚区分。
- 重构只在授权范围内进行；全仓审查先输出问题，不自动批量修改。代码行数只是观察指标，不是完成标准。
- **集成接口要按宿主的真实回调签名测，不是只在自带预览页里测。** 模块交给宿主（例如 `app.js` 的 `canvasTex(w, h, draw)` 把绘图上下文传给 `draw`）之前，测试里必须用忠实模拟宿主签名的替身跑一遍；预览页能打开不等于能接入。
- 画面类验收以**真实浏览器截图**为准（固定镜头、同画质档、与参考效果图对照），不以「模块已完成、测试全过」代替。
- **测试一律带资源上限运行**（2026-10-22 事故：一次失败诊断把单个 node 进程撑到约 19 GB，拖垮整机和 Paperclip）：`node --max-old-space-size=2048 --test --test-timeout=60000 --test-concurrency=2 …`；断言里不要把 Three.js 对象（Mesh / Scene / 几何）直接放进 `assert.equal` 的比较，改比布尔值或 UUID；浏览器自动化用完要关闭，不留残余的无头 Chrome。
- **验证截图用完即清（董事会 2026-10-22 规则）：** 验收用的截图只是验证过程的证据，**验证完成（规划者验收通过）后必须删除**，不长期保留，也不放进 `docs\`；执行者交付时截图放在对应的 `office3d-backup-<任务名>\` 目录里（不要放进 `office3d` 本体），汇报里列出路径，规划者验收后统一清理。**不属于验证截图、不得删除：** 素材与贴图（`assets\`、`asset-intake\`）、董事会提供的参考效果图与概念图（`knowledge\项目\参考\`）、`_quarantine`、预览页与文档里作为功能组成的图片；**董事会要求目视判断的对照图**（例如柬埔寨国境轮廓、R3-7 并排验收图）保留到董事会看完并回复后再删。
- **不要用 pm2 启动或重启 Paperclip**（pm2 以 SYSTEM 身份运行，会让所有 agent 变成 SYSTEM，ssh 密钥等依赖 Administrator 的能力随之失效）；服务启停由规划者或董事会负责，执行者本来就不碰。

## 汇报格式（每个任务都按这个交）
1. 改动文件清单（新增 / 修改，各多少行）和备份目录位置。
2. 任务卡里的要求哪一条没照做、为什么。
3. 测试的完整命令和真实输出末尾（`node --test tests/…`）。语法检查：**`.mjs` 用 `node --check x.mjs`；浏览器模块（`.js`）必须用 `node --input-type=module --check < x.js`**——`node --check x.js` 会把 ES 模块当普通脚本，对模板字符串等错误误报「通过」（治理中心就因此打不开过一次）。改过任何浏览器模块后，必须在浏览器里实际打开 http://office.localhost:3200/ 确认页面能加载、控制台无报错，再交回。
4. 用真实数据（对运行中的服务做只读 GET）验证的结果，贴关键 JSON 片段。
5. 需要人工做的事：重启服务（`server.mjs` 改过才需要；在现有终端里 Ctrl+C 后重新运行 `node E:\VirtualAIOffice\paperclip-ops\office3d\server.mjs`）、浏览器 Ctrl+F5，并列出 3 个肉眼检查点。
