**例外规则：** 只允许修改 `rework.mjs`、`tests/rework.test.mjs`、`README.md`（T13 章节里补一句识别规则）。不要改 `server.mjs`、`ui.js`、`governance.mjs`、`acceptance.mjs`、`standup.mjs`。**不得向 Paperclip 发任何写请求。** 备份到 `office3d-backup-rework-header`（办公室目录没有 Git）。改的是服务端模块，**让人重启服务**（汇报里写明，不要自己结束进程）。

## 现象（我用只读脚本在真实 Paperclip 评论上跑过 `parseReworkComments`）
扫描 224 个任务，11 个含返工相关评论。其中：
- **CMP-274（状态 blocked，仍在进行）被判 `rounds: 3, capped: true`。** 但它的评论里没有任何一条真正的「【第 3 轮退回】」，只是同事在正文里**提到**别的任务：`…CMP-295 第 2 轮退回的 R6、R7 我已就地裁定…`、`…若它逾时或第 3 轮退回，由我就地书面放行…`、`…CMP-297 04:23:59Z 第 3 轮退回 R5 / R7。董事会已接受…`。
- **CMP-296** 同理：一条阻塞评论里引用了「CMP-297 在 04:23Z 给出【第 3 轮退回】R5、R7」，被判 `rounds: 3, capped: true`。
- **CMP-301** 的评论里写 `…出现【第 3 轮修复】+【验收证据】+ 修订提交号` 是在**提条件**，不是修复评论。
- CMP-297 里有一条**真正的**退回：评论**开头**就是 `【第 3 轮退回】复核结论：**REQUEST_CHANGES** ｜ 审查…`；同一任务另一条评论里 `必须退回 → 用「【第 3 轮退回】R… ｜ 对应 AC-x ｜ 问题 ｜ 复现」编号` 是**引用模板**，不是退回。

**后果：** 一旦打开总开关，巡检会对 CMP-274 发一条「已退回到第 3 轮…请不要再自行提交验收」的评论并通知董事会——那是一次**误报**，而且评论会唤醒负责人。这是误报会直接造成打扰的缺陷，必须在开启前修好。

## 根因
`rework.mjs` 的标题正则 `HEADER = /第\s*(\d+|[一二三四五六七八九十]+)\s*轮\s*(退回|修复|复验)/` 是在**评论全文任意位置**搜索，括号、行首都不要求。

## 要求：只认「评论里真正的标题行」
知识库模板（`流程/模板/返工记录.md`）规定标题是独立的**带括号的行首标记**：`【第 N 轮退回】` / `【第 N 轮修复】对象版本：…` / `【第 N 轮复验】R1 通过 …`。据此：
1. 标题必须出现在**某一行的行首**（允许行首有空白，以及 Markdown 的 `#`、`>`、`*`、`**`、`-`、数字序号这类前缀，最多 6 个字符的前缀），且必须被 `【…】` 或 `[…]` 括起来（全角 / 半角括号都认）。正文中间的「第 3 轮退回」「【第 3 轮修复】」一律**不算**。
2. 一条评论里可以有多个标题行（例如先退回再说明），每个标题行各自处理；**同一条评论里的 R 项只归属于它上面最近的一个标题行**（不要把整条评论的 R 项都算给第一个标题）。没有标题行的评论不参与计数。
3. 引用模板的写法要被排除：标题行后紧跟 `…` / `R…` 这种占位（例如 `【第 3 轮退回】R… ｜ 对应 AC-x`）不算真实退回——**退回标题行之后必须能解析出至少一个 `R<数字> ｜ …` 条目**，否则记为「格式不全：退回缺 R 项」放进 `formatIssues`，**且不计入 `rounds`**。
4. 被排除的「提到 / 引用」不要悄悄丢掉：在返回值里加 `ignoredMentions: <数量>`（只给数量，不给正文），方便界面和测试看出过滤生效。
5. 现有行为保持不变：程序评论（含 `【返工巡检】`）不计数、作者必须是 agent 或董事会、中文数字解析、缺 AC / 缺复现、R 编号重排与复用、同项重复、`capped` / `warned` 判定、`isCappedView` 等。
