# NAV-1d-dr-place-mode：仓配地点模式——进入 DR 仓配服务中心后不再出现办公室（取代 NAV-1 的 B 部分；Trae，临时独占 `app.js` / `ui.js` / `index.html`）

**董事会 2026-10-22 指示：「地图上点击仓配中心，进入到仓配中心，不要再出现智序工场·办公室。」**
**现状（我实测）：** `/?campus=1&place=dr` 进去仍是整个办公室：品牌「智序工场 · 办公室」、页面标题「智序工场 · 办公室 3D」、办公室建筑与 25 位同事名牌与前厅、右侧 AI 团队任务面板（含 KhmerX 的 CMP 任务）、相机在办公室默认角度；主页面至今没有读取 `place` 参数。
**目标：** 地点之间**界面与内容彼此隔离**：进入仓配只看到仓配；进入办公室（默认页面）只看到办公室。**这是产品结构里「地点」的第一次真正落地**（见 `NAV-1-town-two-places.md`、记忆 `town-two-places-structure`）。

## 要做的事
1. **新模块 `place-mode.js`（纯逻辑，Node 可测）**：`resolvePlaceMode(search)` → `{ place: 'office' | 'dr', campus: boolean, title, brand, ... }`。规则：`?place=dr`（含旧写法 `?campus=1&place=dr`）→ 仓配地点模式；**`?place=dr` 单独出现也等于开启园区**；不带 `place`、或 `place=office` → 办公室（**默认页面逐数据不变**）；`?campus=1` 单独出现 = 现有的「办公室 + 园区」联合预览（**保持不变**，AS2-2 等验收依赖它）；未知 / 重复 / 大小写异常的参数忽略并回退办公室。
2. **文案与品牌（仓配模式）：** 页面标题「DR 仓配服务中心 · 智序小镇」；顶栏品牌区标题「DR 仓配服务中心」、副标题「仓配地点 · 演示场景」（沿用现有 logo 图，不改文件）；**DOM 与 3D 标签里不得出现「智序工场」「办公室」「AI 同事」「Paperclip」等办公室字样**（`document.body.innerText` 与屏幕标签扫描，测试断言）。
3. **场景（仓配模式）：** 办公区的建筑、前厅与办公区前的 DR 广场、办公家具、25 位同事及其名牌 / 状态环 / 气泡、小橘、董事会与评审室设备、办公区区域标签**全部不显示、不更新**（至少 `visible=false` 并跳过其逐帧更新；能直接不创建更好，但**不要为此重写场景构建**）；保留道路、绿化、天空与**仓配园区**（`dr-campus-*`）。**用截图证明**：从四个相机方位（含朝向办公区那一侧）都看不到任何办公室对象。
4. **面板与菜单（仓配模式）：** 隐藏 AI 团队相关的一切——任务进度面板、「等你处理」、派发任务、同事搜索结果、治理 / 设置里的办公室项、办公室机位按钮（环绕巡航、跟随、形象墙、高棉地标等仅办公室有意义的）；**新增仓配面板**：地点名称、「调度中心」按钮（进入 `dr-console.html`）、「返回小镇」（`/town.html`）、W1 / W2 / W3 作为**流程分区**的简短说明（**不显示 4015 / 1740 / 8004 ㎡**，场景里也不显示）。搜索只搜**园区的区域**（14 个功能区，名称带「示意」），不搜同事。
5. **镜头与小地图（仓配模式）：** 默认机位 = 「建筑正前方偏左、俯视 40°–50°、近似轴测」，目标取 `CAMPUS_BUILDING` 中心附近；机位按钮：全景、货架月台、调度中控、前广场；小地图边界 = 园区（`CAMPUS`），不画办公区。
6. **数据与请求（仓配模式）：** **不轮询 `/state`**，不请求任何办公室 / Paperclip 数据（仓配地点不应暴露办公室任务）；时间 / 天气等顶栏小件若来自 `/state`，仓配模式下改为**本地金边时间**（客户端时钟，`Intl` 时区 `Asia/Phnom_Penh`）或直接不显示；**不新增接口、不新增轮询、零 token、零写入**。局域网 / 大屏的访问控制保持原样（目标页自己鉴权）。
7. **返回：** 顶栏地点栏（`place-bar.js`）显示「当前公司 ｜ DR 仓配服务中心 ｜ 返回小镇 ｜ 调度中心」；返回小镇后再次进入同一地点恢复镜头（`sessionStorage` 包在 `try/catch` 里）。
8. **预算与回归：** 仓配模式的 calls / 三角形**应低于**「办公室 + 园区」联合预览（隐藏办公室后）；默认页面（不带参数）与 `?layout=2`、`?campus=1` 的画面、读数、请求集合逐项不变（路由快照 + 同机位成对测量）；`?place=dr` 下控制台 0 错误。
9. **测试：** `place-mode.js` 纯函数测试（参数矩阵）；仓配模式下 DOM 文本不含禁用字样；网络面板在仓配模式下**没有 `/state` 请求**；默认页面 DOM 与改前一致（哈希对照）；全量 `node --max-old-space-size=2048 --test --test-timeout=60000` 全过。
10. **浏览器验收（必做，Playwright，1280×720，高 / 低档）：** `/?place=dr` 的四方位截图（含朝向办公区一侧）、顶栏与面板近景、调度中心按钮进入 `dr-console.html` 再返回；从 `/town.html` 点击 DR 标记进入的完整路径；后退 / 前进（**启用后退缓存的 Chrome**）各一次无残留状态；`/`（办公室）与 `/?campus=1` 各一张证明未变。
