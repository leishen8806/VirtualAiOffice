# NAV-1-town-two-places：小镇双地点导航 V1（只加导航，不重做场景与业务；A：Trae，B：Codex 会话一）

**董事会 2026-10-22 正式确定的产品结构：** **智序小镇是世界入口；智序工场·办公室与 DR 仓配服务中心是两个地点；仓配调度中心是仓配地点内的专业工作台。统一世界体验，但不把场景、数据和业务流程混在一起。** 两个「指挥 / 调度中心」必须区分：**AI 团队指挥中心**（Agent、研发任务、执行、成本、评审、交付）属于办公室；**仓配调度中心**（仓储作业、运单、车辆、月台、配送）属于仓配地点。

## 硬性规则（开发契约）
- **小镇是入口，不是业务开关**：进入 / 离开任何地点只切换界面，**不启动、不取消、不修改**任何任务、审批、作业；点击建筑只导航与只读，**不创建任务、不调用模型、不写 Paperclip**；刷新只读取既有结果，不重复下发。
- **每个地点都保留直达地址**（收藏 / 链接直接进 `index.html`、`command-view.html`、`dr-console.html`），小镇不是必经之门；三维加载失败时给出工作台 / 列表入口。
- **目标页面自己鉴权**（沿用现有本机 / 局域网访问码 / 只读 / 大屏令牌规则），小镇不放大任何权限；局域网与大屏设备看到的入口与现在一致。
- **「当前公司」**：V1 只显示当前公司名称（单公司）；跨公司拒绝属于多租户 F01，**本卡不做也不得声称已做**。
- 切换地点时，上一页面卸载（页面级导航天然释放渲染与轮询）；**不得新增轮询**，不得让两个重型场景同时在后台运行。
- 默认关闭的开关：`town-nav.json`（缺失 / 损坏 = 关闭，启动时读一次）；关闭时**除 `town.html` 的两个地点标记外**，所有页面与现在逐数据一致。
- **例外（董事会 2026-10-22 指示「加入到金边小镇的地图上」）：`town.html` 上的「智序工场·办公室」与「DR 仓配服务中心」两个地点标记默认就显示**（作为地图地标，不受 `town-nav.json` 控制）；点击标记进入对应地点也默认可用（只是页面跳转，不改业务）。`town-nav.json` 只控制其它页面的地点栏（`place-bar.js`）与主页面的导航钩子（B 部分）。

## A. Trae（模块 + 页面，不改 `app.js` / `ui.js` / `index.html`）
1. **地点栏模块 `place-bar.js`**（浏览器 `.js`，无 `fetch / innerHTML / Math.random / Date.now`）：一条细的顶栏「当前公司 ｜ 当前地点 ｜ 返回小镇 ｜ 工作台入口」，深浅主题，移动端可用；**只做导航链接**，数据只来自页面已有的只读状态（没有就显示「–」）。
2. **`town.html` 地点标记**：在金边底图上加「智序工场·办公室」与「DR 仓配服务中心」两个可点击标记（办公室位置按已确认的办公室坐标、**沿用 P1 的坐标粗化规则**：局域网 / 大屏只显示粗化位置；**仓配中心位置：董事会 2026-10-22 已给出真实坐标 `11.5337037, 104.9725248`**，不再用示意点；与办公室**同样的粗化规则**（本机完全访问显示精确位置，局域网 / 大屏只显示粗化位置），所属 Khan 由 `town.html` 现有 14 个 Khan 多边形**计算得出，不要手写**）；点击 → 短暂过渡 → 进入对应地点；悬停显示建筑名称与简要说明（**不显示任务 / 库存等业务数据**）。
3. **`command-view.html` 与 `dr-console.html`** 引入 `place-bar.js`（各 ≤ 3 行）；**`dr-console.html` 等 Codex 会话二的 S2-10 / S2-11 完成并验收后再改**，避免互相覆盖。
4. 测试：导航映射（地点 → 地址）、开关关闭时零变化、`place-bar` 不发请求、无业务写入口；全量测试带 `--max-old-space-size=2048` 与超时。浏览器：小镇 → 办公室 → 指挥中心 → 返回小镇 → 仓配 → 调度中心 → 返回，全程控制台 0 错误、无新增轮询（网络面板对照）。

## B. Codex 会话一（主页面钩子，`app.js` + `ui.js` + `index.html` 合计新增 ≤ 15 行，逐行列出）
5. `index.html` 引入 `place-bar.js`（开关开启时显示）；**空间入口**：办公室里指挥大屏 / 运维屏点击 → `command-view.html`；园区调度中控屏（`campus-dispatch-simulation`）点击 → `dr-console.html`；**快捷按钮**沿用现有入口位置。
6. **仓配地点模式**：从小镇进入 DR 时用 `?campus=1&place=dr`：默认镜头聚焦园区（正前偏左、俯视 40°–50°，与 AS2-2 的固定机位一致），地点栏显示「DR 仓配服务中心」；`?place=office` 或不带参数 = 办公室。**V1 不改加载方式**（园区仍与办公室同一场景）。
7. **返回小镇**后再回到同一地点，恢复原镜头（`sessionStorage`，包在 try/catch 里，失败就用默认镜头）。
