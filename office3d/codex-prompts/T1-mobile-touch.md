# T1-mobile-touch：手机 / 平板的局域网看板（触屏手势 + 响应式）

先读 `_common.md`。

【背景】办公室现在开放了局域网只读访问（`README.md`「局域网访问」一节），同事会用手机、平板打开 `http://<IP>:3200/`。目前页面按桌面设计：右侧「等你处理」面板、左上「今日工作情况」、底部工具栏在窄屏上互相挤压，3D 画面只支持鼠标操作，手机上几乎没法用。

【任务】让页面在 360–1024px 宽的触屏设备上可用，**桌面体验不变**。

## 允许修改
`index.html`（样式）、`app.js`（触屏手势、小地图）、`ui.js`（只改弹窗的窄屏表现）、`README.md`（加一节说明）。**不要改 `server.mjs`**。
注意：这些文件近期已经被改过很多次（工具栏分组、小地图、点地面走过去、治理中心、额度健康弹窗、全局搜索等），**在当前版本上改，不要用任何旧备份整份覆盖**；新增的弹窗（治理中心、额度与运行健康、全局搜索面板）在窄屏上也要可用。

## 要求
1. **布局**：≤900px 时，「等你处理」「今日工作情况」默认折叠成顶部的两个小按钮，点开后以底部抽屉（占高度 ≤60%）显示，再点收起；底部工具栏已经整理成三个向上展开的分组菜单（📋 查看 / ⚖️ 治理 / ⚙️ 设置）加「全屏」「面板」两个按钮（见 `README.md`「底部工具栏分组」，分组逻辑在 `app.js`），**保持这个结构**：窄屏下它们仍排成一行，菜单向上展开并且不能超出屏幕左右边缘（靠右的「设置」菜单已经是向左展开），**不要**给 `#tools` 加 `overflow`（会把向上展开的菜单裁掉）；不遮住 3D 画面的中间区域；`#help` 提示在触屏上隐藏。点人物弹出的详情卡、各弹窗在窄屏上占满宽度、可滚动、有明显的关闭按钮。
2. **手势**（只在 `pointerType === 'touch'` 时生效，鼠标行为不变）：单指拖动 = 旋转；双指捏合 = 缩放；双指拖动 = 平移；单指轻点地面 = 走过去（已有 `walkTo`）；轻点人物 = 看详情；双击 = 拉近。注意现有 `pointerdown/move/up` 里已经有双指缩放的雏形（`ptrs` 的 `pinch`），在它的基础上补全，别重写镜头系统。
3. **小地图**：触屏上放大到宽 ≥160px、可点可拖；`@media (max-height: 560px)` 现在会隐藏它，改成横屏手机上仍显示一个更小的版本（宽 ~120px）。
4. **性能**：触屏设备默认把画质降一档（沿用现有「画质」切换逻辑，不要新增选项），`devicePixelRatio` 上限 2；不要为触屏新增任何每帧运行的重计算。
5. 局域网设备是**只读**的：页面里所有会 POST `/act` 的按钮在 `state.lan === true`（`/state` 已下发）时置灰，并在悬停 / 长按时提示「局域网只读，请在运行服务的电脑上操作」。不要改服务端的 403 逻辑。

## 验收
- 用浏览器开发者工具的设备模拟（iPhone SE 375×667、iPad 768×1024、横屏 667×375）逐一检查：无横向滚动条、无元素重叠、所有按钮能点到；写出你检查了什么、没检查什么。
- `node --input-type=module --check < app.js` 和 `< ui.js`（不要用 `node --check x.js`）；桌面 1280×720 下截图对比，布局与改动前一致（说明比较方法）。
- 未验证的（比如真实手机上的触感）如实写「未验证」。
