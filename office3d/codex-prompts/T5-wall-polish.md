# T5-wall-polish：大屏页打磨（领导视图）

先读 `_common.md`。**本任务的例外规则**：允许修改 `wall.html`（新页面，主要工作都在它里面）；`index.html` / `ui.js` / `app.js` / `server.mjs` / `wall.mjs` / `roadmap.json` **不要改**（数据与权限由 Claude 负责，如果你发现 `/wall/data` 缺字段，写进汇报，不要自己改服务端）。可以新增 `wall.css`、`wall.js`（拆分 wall.html 里的样式和脚本）和 `tests/wall-page.test.mjs`（只测纯函数）。

【背景】`/wall` 是给公司领导在大屏幕（会议室电视 / 投影，1920×1080 和 3840×2160）上看的页面，离屏幕 3–5 米，**没有人操作鼠标键盘**。现在已有一个能用的版本（`wall.html`）：左边 iframe 嵌入 3D 办公室（`/?wall=1`，无面板、自动巡游），右边是领导视图卡片，数据来自 `GET /wall/data`（先请求一次，贴出完整 JSON 看清字段；字段含义见 `wall.mjs` 顶部注释和 `README.md`「大屏」一节）。你的任务是把它做成「会议室里真的能看」的水平。

## 要求
1. **远距离可读**：1920×1080 下正文字号 ≥ 20px、关键数字 ≥ 64px，对比度达标（深色背景）；不靠颜色单独表达状态（风险灯旁要有文字，里程碑除颜色外有图标或文字）；避免大面积纯白刺眼。
2. **信息分层**：一眼看到三件事——① 风险灯（红黄绿 + 一句话原因）；② 上线进度（当前里程碑、计划上线日、下一个里程碑还剩几天 / 已超期几天）；③ **需要领导决定的事**（有则突出，无则显示「没有需要决定的事」）。其余（项目进度、今日数字、晨会结果、近期完成）放次要区域。数据里有 `highlights.standup` / `acceptance` / `committee` / `recentDone`，页面现在没用，请合理展示（晨会：今天决定做哪几项；近期完成：滚动播放）。
3. **自动轮播而不是堆满**：次要区域按 15–20 秒一页轮播（项目进度 → 今日晨会 → 近期完成 → 里程碑明细），带页码点；轮播不影响主要三件事一直可见。镜头轮播（`SHOTS`）保留，并在画面角落显示当前镜头名。
4. **晨报播报**：每天晨会结束后（`highlights.standup.state` 为 done / awaiting），在主区域自动显示一次「今日晨会」全屏卡片 20 秒（今天做哪几项、谁负责），之后恢复；同一天只播一次（用 `localStorage`，读写包 try/catch）。
5. **稳**：断线 / 接口 401 / 403 / 500 时保持最后一次的数据并显示数据时间；超过 10 分钟没成功拉取，整页变灰并显示「数据已过期」；iframe 加载失败时显示备用画面而不是黑屏；防烧屏：每分钟让内容整体偏移 ≤2px 循环（不能引起抖动感）；整页每 6 小时刷新一次（已有）。
6. **适配**：16:9 和 4:3 都不能溢出；窗口缩放不出现滚动条；`prefers-reduced-motion` 下关闭轮播动画。
7. **安全**：所有来自数据的文字都必须转义（用 `textContent` 或 `esc()`）；不得请求 `/wall/data` 和 `/state` 以外的接口（其他接口对大屏令牌一律 403）；不得在页面或日志里出现令牌。
8. 纯函数（格式化、轮播页选择、过期判断、晨报是否已播）抽出来写 `tests/wall-page.test.mjs`（`node:test`），至少覆盖：空数据、里程碑超期 / 刚过期 / 还有 N 天、决定列表很长、数据过期判断、同一天晨报只播一次。

## 验收
- `node --test tests/wall-page.test.mjs`；若新增了 `wall.js`：`node --input-type=module --check < wall.js`（不要用 `node --check x.js`）。
- 用浏览器分别以 1920×1080、3840×2160、1024×768 打开 `http://office.localhost:3200/wall`（本机预览不需要令牌），各截一张图贴在汇报里，并逐条说明上面 8 条是否满足；3 米外可读性无法真机验证的，如实写「未验证」。
- 对运行中的服务只读 GET `/wall/data`，贴完整 JSON；说明页面上每一块分别用了哪个字段。
- 不要改服务端；不要新增依赖；不要联网加载字体或图片（全部离线）。
