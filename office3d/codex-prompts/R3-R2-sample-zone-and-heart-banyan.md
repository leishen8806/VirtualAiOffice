## 二、样板区范围与验收口径
- **范围：** 中央环形茶水吧（Ø12）+ 4 m 环形主通道 + 前厅接待 16×8（咖啡吧台、前台、休闲沙发组、玻璃门面与闸门）。**样板区通过前，不扩散到全办公室和广场。** R3-R 里其余项（四角展示间、开放办公区、广场）排在样板区之后。
- **茶水吧要成为完整设施：** 有厚度的环形台体与台面、内侧操作区、吧台设备（占位体量即可）、吧椅、外围弧形休闲座椅与花箱；台体用木材 + 浅色台面 + 克制金属收边，**树冠不得遮住整个吧台与座位**。
- **材质区分，不是统一刷米黄：** 吧台木纹层次、地面淡石纹与接缝、沙发织物感（粗糙度高）、框架金属感、玻璃通透。色板沿用 `暖白 #F4F1EA / 浅米 #D9D3C6 / 金 #B89B64 / 灰绿 #B7C2B4`，**可在此基础上加木色 `#C9A57A`、藏青 `#2F4A5C`、墨绿 `#3E5A4E`**。
- **玻璃：** 现在偏乳蓝、存在感超过家具——改成更通透（降低不透明度与蓝色相），由细框架、门与少量反射表达分区；**透明对象单独调排序与深度写入，不要全场套同一参数。**
- **明暗层次：** 稳定简单的照明先把空间做清楚——桌腿落地感（接触阴影）、吧台厚度、墙角深浅、玻璃后家具仍可读；不加大面积泛光、强反射、动态灯效。「暖色」≠整体调黄，「明亮」≠所有表面接近白色。
- **预算不变：** 全办公室累计 ≤ +12 calls / ≤ 90k 三角形（主场景口径）；植物、吧凳、座椅全部实例化。

## 三、中央树改为「缩景版·福州三坊七巷爱心榕树」（B 做资产，A 接线；**静态样板先行**）
**参考：** 董事会提供的央广网图文（南后街安民巷附近、树冠天然近似爱心的榕树）。**保留的是自然树冠形成的爱心轮廓，不是标准心形雕塑；只作形态参考，不把新闻照片当纹理，不下载外部素材（程序化生成）。** TikTok 链接未能读取，不据此补细节。
| 部位 | 要求 |
|---|---|
| 树冠轮廓 | 顶部左右两个自然隆起，中间有清楚但不过深的凹口，下部逐渐收拢连接树干；左右略不对称，边缘由细密叶簇构成，**不要绝对对称或塑料般光滑** |
| 树干 | 灰褐色，有自然纹理与分枝关系，不是一根细圆柱撑大树冠 |
| 叶色 | 自然中深绿，少量嫩绿变化；**不用当前的浅青蓝，不用荧光绿**；**小叶叶簇**（不要直接用龟背竹 / 琴叶榕 / 发财树 / 花叶绿萝的大叶片图集填树冠） |
| 树池 | 暖米色石材，直径约 2.0 m、外沿高约 0.4 m，内部低矮地被或简洁种植面，不摆杂乱装饰，与吧台协调 |
| 尺寸（起模建议，按实际场景单位、净高与岛台关系校准，**不得为放树而缩放办公室、挪工位或改变人物走位**） | 总高约 3.8 m、冠幅约 4.0 m、冠深约 2.5–3.0 m |
| **朝向** | 爱心主观赏面朝 **前厅入口 → 中央岛台**这条中轴（南向 +z）；**不得随镜头转**；侧面保持正常树冠厚度，不要求所有角度都是完美爱心 |
- **实现提示（B）：** 用若干个实例化的小叶叶簇（`InstancedMesh`，按「心形包络 + 噪声」散布，固定随机种子），一个树干 + 3–5 条分枝；总三角形 ≤ 8k、**calls ≤ +3**。**先交静态样板**；造型通过后才考虑「非常轻微的叶簇摆动」，树干与整棵树不得摇摆或周期缩放。
- **验收三个画面：** ① 默认总览（`concept` 机位）；② 从前厅走近的人眼高度视角；③ 斜侧近景。要求：①② 一眼认出爱心榕树与双峰凹口；②③ 吧台与座位仍清楚可见；树不退化成圆球或扁平树盘。
