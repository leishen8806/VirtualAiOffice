# T18-cat-play：小橘可以被逗（点击互动 + 逗猫棒 + 小球），纯前端、零成本、纯装饰

先读 `_common.md`。**本任务的例外规则：** 允许修改 `app.js`（**只限**小橘互动的挂钩和 `fun.pick(ray)` 周边的点击处理）、`fun.js`（如果小橘逻辑在这里；先 `grep` 确认文件名和位置，`fun.catInfo()`、`fun.pick(ray)` 是入口）、`index.html`（**只限**一个「逗猫」工具按钮和对应样式）、`ui.js`（**只限**必要的 toast / 按钮挂钩）、新增 `cat-play.js`（互动状态机放这里，尽量让 `app.js` 只留几行挂钩）、新增 `tests/cat-play.test.mjs`、`README.md`。**不要改** `server.mjs` 和所有 `*.mjs` 业务模块，不要新增 3D 模型 / 纹理 / 音频文件 / 外部依赖。纯前端，不需要重启服务，验收时 Ctrl+F5。备份到 `office3d-backup-cat-play`（办公室目录没有 Git）。**不要与改 `app.js` 的其他 Codex 任务同时进行。**

【背景】董事会要求「小橘也能逗猫」。现在点击小橘只会弹出 `🐱 小橘（办公室猫，纯装饰）：…`。我们有一条硬规则：**办公室里的「工作动画」只来自真实事件**；逗猫是**用户主动触发的纯装饰互动**，不是工作数据，所以允许，但必须**明确标注为装饰**，**不得**让它看起来像真实的工作状态，**不得**写入事件账本 / 回放 / 协作关系图 / 统计，**不得**产生任何网络请求。

## 要求
1. **点击小橘**：小橘有反应（按当前状态在几种之间随机、不重复连续两次）：喵一声（头顶气泡「喵~」，不发声音）、蹭一下（原地小动作）、伸懒腰、跳到附近一个安全点（走地面，不穿墙不穿家具）。冷却 1.5 秒，防止连点刷屏。
2. **逗猫棒模式**：工具栏加一个「🧶 逗猫」开关（放在现有「设置」或「查看」菜单里，沿用现有分组）。开启后鼠标在地面上的位置出现一个小逗猫棒标记（一个简单的 2D 或小几何标记，**不新增模型文件**），小橘会**慢慢走向并追逐**它（速度比人慢，到达后做「扑」的小动作，然后继续追）；关闭或 15 秒没有鼠标移动自动退出；Esc 退出。**不能影响人物走位和点击拾取**：逗猫模式下点击地面仍然只用于逗猫，不触发「点地面走过去」；退出后恢复。
3. **小球**：逗猫模式下按住 Shift 点击地面，在该点放一个小球（简单球体，≤1 个同时存在，最多存在 10 秒），小橘去拨弄它（小球被拨动滚几步后停）。球不得滚出建筑范围或穿墙（沿用 `office-layout.js` 的包络和房间墙）。
4. **边界与安全**：小橘只在公共区域（走廊、前厅、休息区、DR 广场、空地）活动；**不进入任何房间**（评审室投票会、董事会、会议室、工位房间不得出现猫在桌上或穿墙）；追逐目标在房间里时，小橘停在门外并朝门里「看」。**不得与人物碰撞重叠**：沿用 `pedestrian-traffic.js` 的避让常量，人走过时小橘让路。
5. **装饰标注**：逗猫模式开启时屏幕角落显示小字「🐱 逗猫中（纯装饰，不影响工作数据）」；点击小橘的 toast 文案保留「纯装饰」字样。
6. **不增加渲染负担**：不新增光源、不新增阴影投射、不新增大纹理；`low` 画质档（如已有 `?q=low`）下逗猫棒标记用最简几何，小球无阴影；逗猫关闭时**零开销**（不跑额外的每帧逻辑）。
7. **纯函数可测**：状态机（`idle` / `chase` / `pounce` / `batting` / `wander`）、目标选择、公共区域判定、冷却、小球寿命，抽到 `cat-play.js` 的纯函数里。

## 测试（`tests/cat-play.test.mjs`）
- 公共区域判定：走廊 / 前厅 / 休息区 / DR 广场 / 空地为真；所有房间（含评审室、董事会、计划室）内部点为假（用 `office-layout.js` 的真实房间数据，不要写死数字）。
- 追逐：目标在房间内时，小橘的停靠点在门外且不在门洞里；目标在公共区域时会收敛到目标附近。
- 冷却 1.5 秒、「不连续重复同一个反应」、小球最多 1 个且 10 秒后消失、15 秒无鼠标移动自动退出。
- 人物避让：小橘与人物水平距离小于阈值时让路（用现有避让常量）。
- 逗猫关闭时状态机不更新（零开销断言：关闭后调用 `update` 返回 `false` 且不改变状态）。

## 验收（缺一不通过）

- **浏览器实测**（`http://office.localhost:3200/`，Ctrl+F5）：点击小橘 10 次（每次反应不同于上一次、冷却生效）；开启逗猫棒，移动鼠标到前厅、走廊、DR 广场，小橘追过去；把鼠标移到**工程办公室里面**，小橘停在门外；Shift 点击放球，小橘拨球；15 秒不动自动退出；Esc 退出；退出后「点地面走路」恢复正常。截图 3 张（追逐、拨球、停在门外）。
