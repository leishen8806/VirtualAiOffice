# 小镇线共用规则（所有「小镇线」任务都隐含包含本页；先读 `_common.md`，再读本页）

> 董事会 2026-10-21：小镇线（生活化 / 经济 / 世界）与主线（主流程优化）并行；**小镇线不得影响业务流程管理**。本页是隔离契约的执行版，验收时逐条检查。

## 一、任务粒度与交付方式
- **每个任务按约 1 小时设计**：范围小、边界清楚、验收可核对。**做不完就停在可验证的最小子集并如实汇报，不要硬撑、不要扩大范围。**
- **完成的唯一标准**：`node --test tests/*.test.mjs` 全过（基线以实际为准，当前 **574 项起**）；汇报写「做到 / 没做到 / 未验证」；**汇报必须与磁盘一致**（董事会侧会核对文件与测试）。
- 开工前备份将改的文件到 `office3d-backup-<任务名>\`（办公室目录没有 Git）。

## 二、隔离契约（小镇线必须遵守）
1. **零 token，不碰 Paperclip 写路径**：不发评论、不建任务、不唤醒同事、不调模型、不写进同事上下文；不得对 Paperclip 发 POST / PATCH / PUT / DELETE。
2. **所有新功能默认关闭**：独立 JSON 开关（如 `town-home.json`），缺失 / 损坏 / 非布尔 `true` 一律视为关闭；**关闭时对既有所有路由、页面、响应头逐字节不变**（验收用 `node tools/tenancy-snapshot.mjs <输出文件>` 与改动前快照对比；**开工第一步先对运行中的旧服务拍快照**）。
3. **故障隔离**：小镇模块出错只降级自己；不得影响 `/state`、治理中心、任务面板、对话、审批卡片；所有新入口 `try/catch`，失败不抛到主循环。
4. **性能预算**：不得提高主线页面首屏时间与轮询频率；新增轮询必须有 `document.hidden` 守卫；绘制调用预算沿用 S1-6 基线（DR 广场高档增量 ≤ +10、低档 ≤ +4，**新功能默认关闭时增量为 0**）；资源有上限（对象数、缓存、队列）。
5. **不改变主线的派发 / 审批 / 返工 / 验收流程**；生活 / 经济 / 考勤数据**不得**成为任务派发、岗位增减、预算的依据。
6. **时间域分离**：游戏时间、昼夜、通勤动画不改变任务截止、预算周期、审批有效期；**浏览器计时器 / 动画帧不是权威时钟**。
7. **记忆与账本分离**：生活事件不进工作知识库；DR 数据不进真实成本与任务决策；**本系列（A 系列）不涉及 DR 币**。
8. **三类人物标识**：工作 Agent / 真人 / 生活 NPC 必须能区分；NPC 标明「模拟角色」。
9. **基础功能永远可用**：基础住所、基础工位、工作入口不以任何玩法为前提。

## 三、热点文件所有权（避免互相踩）
| 文件 | 规则 |
|---|---|
| `app.js` | **同一时间只有一个任务能改**（看板标「改 app.js」的任务互斥）；新功能写成**独立模块**（`home-*.js`），`app.js` 只留最小接线（≤ 30 行，列在汇报里） |
| `ui.js` / `index.html` | 能不动就不动；新界面放独立模块与独立容器；确需最小钩子，≤ 10 行并逐行列出 |
| `server.mjs` | **同一时间只有一个任务能改；主线任务优先**；小镇线只允许加「仅本机、带令牌、默认关闭」的接线，**逐行列出，不碰任何既有访问控制判定** |
| `office-layout.js` / `env.js` | 只新增导出 / 只扩展既有特例；不改已有值 |
| `town\`（经济引擎）、`town*.js`、`foyer*`、`director.js` | 按任务卡允许范围 |

## 四、共同的测试纪律
- 纯函数模块**不引用** `THREE / document / window / fetch / Math.random / performance.now`（随机性由调用方传入种子 / 时钟）；静态测试固定这一点。
- 新增代码**不得出现** `buy / purchase / price / balance / wallet` 命名（A 系列无交易）；不得 `innerHTML` 拼接外部数据；不得 `eval / new Function`。
- 既有测试**不得放宽或删除**；确需调整的只能是「与本任务直接相关」的断言，并在汇报里逐条列出理由。
- 浏览器实测：用 `?` 参数或开关开启功能；**页面保持聚焦**；读 `renderer.info` 要在页面渲染循环里读（不要手动 `render()`）；控制台 0 错误；**测完把任何临时开关文件恢复原状并写明**。

## 五、服务运行方式（重要）
办公室服务与上班调度由 **pm2** 托管（`office3d` / `office-workhours`）。**不要自己启动第二个 `node server.mjs`（会重复 Telegram 轮询）；不要自己重启服务**——需要重启时在汇报里写明，由董事会侧执行 `pm2 restart office3d`。
