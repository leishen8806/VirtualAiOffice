## 要做的事
1. **外壳模块 `shell3`**（经办公区注册口登记；`?layout=3` 才创建）：60 m 宽外框（按 `LAYOUT_V3`）、**外墙实体 4.5 m**（局部挑高位置按 R3-1）、室内隔断（办公室内 2.2 m、玻璃通透度沿用令牌 0.62；会议 / 董事会下部 0.9 m 实体墙 + 上部玻璃）、门洞净宽 ≥ 1.5 m、**2.5 m 绿化景观缓冲带**（铺装 + 花池 + 低矮灌木占位，植物模型另立卡，本卡先放程序化占位）、地面分区（石材 / 浅木 / 前厅铺装）。**配色继续用办公区暖色令牌（`office-theme-v2.js`），不得出现深蓝科技色。** 门头牌沿用已修的着色器；低档画质沿用 rev2 的简化策略。
2. **外墙遮挡策略（按 R3-1 方案实现）：** 4.5 m 外墙在低机位 / 跟随 / 环绕机位下不得遮挡室内。实现「靠近相机一侧的外墙随相机俯仰角淡出 / 下沉」（或 R3-1 选定的方案），**按帧只更新少量 uniform，不每帧遍历网格**；写出各机位（全景、环绕巡航、俯视、等距、低机位、跟随）在 `?layout=3` 下的默认参数；**`?layout=2` 与默认页面的相机逻辑逐项不变**。**相机默认角度调高**仅在 `?layout=3` 生效。
3. **拆除（`?layout=3` 下）：** 按 R3-1 的拆除清单，让以下对象在 `?layout=3` 下**不创建 / 不渲染 / 移位**：rev2 外壳与家具与吧台、旧中庭 / 前厅布局、旧 DR 广场内部（24×14 矩形）及配套、DR 广场西侧旧仓库外壳（`x=-42…-14, z=17…29`）、与新外框 / 广场 / 绿化带冲突的树、路灯与铺装。**文件与模块不删除；`?layout=2`、默认页面零变化**（用路由快照与同机位成对测量证明）。碰撞体同步：被拆除对象的碰撞体不得残留（写测试 / 检查）。
4. **预算（同机位同画质成对，切换 `office3-root` 可见性取精确增量）：** `?layout=3` 外壳高档累计 ≤ +6 calls、≤ +20k 三角形；低档 ≤ +3 calls。超出按「植物占位 → 花池 → 地面分区」顺序降级并如实写出。
5. **测试：** 外壳数据与 `LAYOUT_V3` 一致（墙段、门、高度）；拆除清单每一项在 `?layout=3` 下不存在、在 `?layout=2` / 默认下仍存在；遮挡策略纯函数（给定相机角度与墙法线，输出不透明度）；`dispose` 释放；静态检查（无 `fetch / innerHTML / Math.random / Date.now`、无 `dr-campus` 引用、无深蓝科技色字面量）；全量 `node --max-old-space-size=2048 --test --test-timeout=60000` 全过。
