## 要做的事
1. **开关**：新增 URL 参数 **`?campusTex=1`**（仅在 `?campus=1` 下有效）；不带该参数时画面、读数、请求与现在逐项一致。低档画质**忽略** `campusTex`，**+0 call、+0 请求**。默认是否开启由董事会看样板后决定，不要自己改。
2. **样板范围与贴图（只做这几项）：**
   - **一排高位货架**（取最靠近收发货月台的那一排，其余排保持现状）：立柱蓝 / 横梁橙使用 `campus-rack-paint`（左蓝右橙色带取对应半幅，带细微磨砂与磨损；**颜色仍须贴近色板：蓝 `#2F6FA8`、橙 `#E8832A`**）。
   - **货物**：该排货架上的纸箱用 `campus-carton-atlas`（4 种箱面随机但**确定性**分配，固定种子），缠绕膜托盘用 `campus-pallet-wrap`（平铺，横向缠绕纹）。
   - **仓内地面**：`campus-floor-concrete`（含黄色安全通道线）；**黄线必须与通道方向一致且落在通道中心**，如需旋转 / 对位，逐项写出；不要让黄线出现在货架下。
   - **月台前沥青**：`campus-asphalt-dock`，白色停车划线与月台位对齐（对位不上就写出差异，不要硬凑）。
   - **不做：** 卡车涂装（`campus-truck-livery`，S2-6b 再做）、棕榈叶（`campus-palm-atlas`，需新增片状模型，另立卡；且是否可用取决于 AS2-0 的判断）。
3. **UV 与合并**：沿用注册口的静态网格按材质合并（不破坏 `dr-campus-registry.js` 的合并）；贴图件的 UV 在构建时按**世界坐标平面投影**生成（地面 / 沥青）或按**模型局部尺寸**生成（货架色带 / 纸箱 / 托盘），每种贴图一个共享材质、同贴图合并为一个批次。
4. **加载与降级**：仅在 `?campus=1&campusTex=1` 时异步懒加载（带 8 秒超时）；任何一张失败只回退该材质为现有版本、页面不报错、控制台一条提示；`sRGB`、`anisotropy ≤ 4`、mipmap、`RepeatWrapping`；`registry.dispose()` 时释放。**零新增外部请求。**
5. **预算（同机位同画质成对测量，切换园区根可见性取精确增量，主场景口径）：**
   - `?campus=1&campusTex=1` 相对 `?campus=1`：**高档累计增量 ≤ +6 calls、≤ +1k 三角形**（S2-4b 合并后高档已有 +11 calls / 低档 +2，注意这是新增在其上的上限；超出就按「纸箱图集 → 缠绕膜 → 沥青」的顺序放弃并如实写出，**不得放宽预算**）；**GPU 贴图内存估算 ≤ 24 MB**，传输 ≤ 2 MB。
   - 默认页面与 `?campus=1`（不带 `campusTex`）逐数据不变。
6. **性能与稳定性**：首帧不得因贴图解码卡顿 >100 ms；5 分钟无增长的纹理 / 几何数量；S2-6 的叉车 / 卡车 / 传送带动画不受影响（动画读数与改前一致）。
7. **测试**：UV 生成纯函数测试；确定性纸箱分配（同种子同分配）；加载失败回退；低档忽略；`dispose` 释放；静态检查（无 `fetch / innerHTML / Math.random / Date.now`，不引用 `office-*`）。全量 `node --max-old-space-size=2048 --test --test-timeout=60000` 全过，不放宽任何断言。
