# AS1-3d-asset-intake：引入免费可商用 3D 素材包（先清单、后下载、再接入；分两段执行）

**执行者：Codex（会话二，仓配产线；办公区素材也由本卡统一审核，接入时各归各线）。** **董事会 2026-10-21 已批准原则：允许引入免费可商用的 3D 素材包以提升观感。** 但**每一次实际下载都必须先列出文件名、来源网址、大小、许可证，由董事会确认后才下载**——所以本卡分两段：**第一段只出候选清单，停下等确认；第二段才下载与接入。**

先读：`_common.md`、`_lane-town.md`、`assets3d.js`（现有 GLB / FBX 加载方式与缓存）、`vendor\three\`（版本，确认可用的加载器：`GLTFLoader`、`DRACOLoader`、`KTX2Loader` 是否在 `vendor\three\jsm\` 里）、`quality.js`（只读：画质档如何合并 / 降级）、两张效果图（办公区 `参考\2026年10月21日 11_16_22.png`、仓配 `参考\智序小镇·DR仓配服务中心概念图.png`）、O4 / O6 / O7 与 S2-5 / S2-6 / S2-8 卡片（了解哪些物件需要模型）。

## 第一段：候选清单（不下载，约 45 分钟）
产出 `docs\asset-candidates.md`，**分两张表**（办公区 / 仓配，**两条产品线的素材不混用**）：
- 需要的物件：**办公区**——办公桌椅、会议长桌 / 圆桌、沙发、吧台与吧凳、书架、绿植（大中小）、显示器、前台、人物（可选）；**仓配**——高位货架、托盘、货箱、叉车、厢式卡车、传送带、月台门、交通锥 / 护栏、绿植（热带）、工人（可选）。
- 每个候选素材包写：**名称、作者、来源网址（官网原始地址，不用转载站）、许可证全称（优先 CC0；CC-BY 必须写明署名要求；不接受「仅限个人 / 非商用 / 编辑使用 / 来源不明」）、包内文件格式（优先 `.glb / .gltf`；`.fbx / .obj` 需说明转换方式）、下载文件名、压缩包大小、解压后大小、包含的物件清单、单个模型三角形量级、风格是否与对应效果图相符（办公区偏暖白 / 浅木；仓配偏写实工业）**。
- **推荐方案**：每条产品线选 1–2 个包，给出**总下载量（目标 ≤ 30 MB 合计，单包 ≤ 20 MB）**、预计新增三角形与 calls、需要的加载器。
- **只能用官方、可追溯的来源**（如作者官网、itch.io 作者页面、Poly Pizza / Kenney / Quaternius / KayKit 等原始页面）；**不得**使用搜索结果里的二次打包、网盘、来路不明的镜像。
- **停下等董事会逐项确认**（我会把清单转给董事会，确认后通知你进入第二段）。

## 第二段：下载、审核与接入（董事会确认后才做，约 1–1.5 小时）
1. **下载与隔离**：只下载董事会确认过的文件；放到新的空目录 `E:\VirtualAIOffice\paperclip-ops\asset-intake\<包名>\`（**不在 office3d 里**），**只解压、不执行任何其中的脚本 / 程序**；拒绝包含 `.exe / .bat / .ps1 / .js / .html / .py` 等可执行或脚本文件的压缩包（发现即停下汇报）；记录每个文件的 SHA-256。
2. **许可留档**：每个包复制原始 `LICENSE` / 许可说明到 `office3d\assets\third-party\<包名>\LICENSE`，并写 `office3d\assets\third-party\MANIFEST.json`（包名、作者、来源网址、许可证、下载日期、文件清单与 SHA-256、哪些模型被实际使用、用于哪条产品线）；CC-BY 素材在 README 与页面「鸣谢」处给出署名。
3. **筛选与优化**：只拷贝实际要用的模型到 `office3d\assets\models\office-v2\` 或 `office3d\assets\models\dr-campus\`（**两条产品线目录分开**）；转为 `.glb`（如需），合并 / 压缩纹理（单张 ≤ 1024²，优先共享材质），**删除未用的动画与高模**；单个模型三角形上限：桌椅 / 小件 ≤ 2k、车辆 ≤ 6k、货架节段 ≤ 1.5k、人物 ≤ 5k；**总新增体积 ≤ 30 MB**。
4. **加载规则**：素材**只在对应开关下加载**（办公区 `?layout=2`，仓配 `?campus=1`；默认页面不请求、不创建任何新素材对象——用路由快照与网络面板验证）；按需懒加载、带超时与失败回退（**加载失败就退回现有的程序化简化模型，页面不报错**）；低档画质使用简化模型或隐藏小件；重复物件用实例化。
5. **本卡不接入场景**：只交付「可用模型 + 清单 + 许可留档 + 一个独立预览页 `asset-preview.html`（两条产品线分两个标签，显示每个模型、三角形数、体积、许可证）」；**接入由 O4 / O6 / O7（办公区）与 S2-5b / S2-6（仓配）各自完成**。

## 验收（两段分别验收）
- 第一段：`docs\asset-candidates.md` 清单完整、来源可追溯、许可证明确、体积估算；**未下载任何文件**。
- 第二段：仅下载已确认的文件；隔离目录与 SHA-256 记录；`MANIFEST.json` 与每包 `LICENSE` 齐全；无可执行 / 脚本文件进入 `office3d`；`asset-preview.html` 可打开、控制台 0 错误、无外部请求；默认页面逐数据不变；`node --test tests/*.test.mjs` 全过（新增一条测试：`MANIFEST.json` 中每个被使用的模型都有许可记录，且没有 `assets\models\` 下未登记的文件）。
- 汇报「做到 / 没做到 / 未验证」，与磁盘一致。**不要自己重启服务。**
