## 要做的事
1. **库存面板**（页面内，`home.html` 的「仓库」标签或独立页）：按类别（家具 / 装饰 / 植物 / 灯 / 挂画 / 地毯）分组显示 12 种物品的**缩略图（用 `home-items-3d.js` 渲染到小画布，或用占用格示意图，二选一，保证低成本）、名称、占用格 `w×d`、拥有数 / 已摆放数 / 剩余数、来源标签（v1 只有「初始赠送」）**；顶部汇总（物品种类、总件数、已摆放、剩余）；搜索框与类别筛选（纯前端，确定性排序）。
2. **进入个人空间**：每个物品卡有「去布置」→ 切换到房间标签并预选该物品进入放置状态（沿用 A5a 的编辑器接口）；面板顶部「进入个人空间」按钮。
3. **数据来源**：优先用 A5b 的 `GET /town/home/layout` 返回的库存；离线演示模式（接口 404 / 403）显示 `starterInventory` 的演示库存并标注「演示」；**不发写请求**。
4. **主页入口钩子**：`ui.js` / `index.html` 里**只加一个入口**（≤ 10 行逐行列出），默认可见与否遵循「小镇线默认关闭」：**入口仅在本机完全访问时显示**（局域网只读与大屏模式不显示）。**改完 `ui.js` 必须在浏览器里验证：加载遮罩消失、没有红色错误条、控制台 0 错误、入口点击能打开新页面。**
5. **文案红线**：不出现「购买 / 价格 / 余额 / 交易 / DR 币 / 提现」；仓库**不代表现实资产**，页面底部固定一行「示意 · 虚拟物品，不对应现实资产权益」。
