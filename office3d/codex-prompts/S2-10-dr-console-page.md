## 数据（`dr-console-data.js`，纯函数、确定性）
- `buildSnapshot({ seed, timeSlice })` → **带版本的 `DrConsoleSnapshot v1`**：`{ schemaVersion, mode:'demo', generatedAt, warehouses:[W1,W2,W3], inventoryByCategory, pallets, waybills, vehicles, tasks, devices, alerts, events }`；**KPI 全部由这些底层数据推导**（总库存 = 各分类托盘数之和；利用率 = 已用库位 / 总库位；在库车辆 = 车辆列表里 `inYard` 的数量；作业任务 = 任务列表计数……），**任何数字不得手写成独立常量**（样式图的数字可以作为演示种子的参考量级，但最终显示值来自推导）。
- `eventsUpTo(snapshot, timeSlice)`：确定性事件流（货物出库扫描、车辆进场登记、托盘上架、分拣任务完成、库存调整、月台占用……）；每个事件带 `id`（幂等）、`at`、`zone`、`kind`；**同一 `timeSlice` 永远得到同样的结果**；不使用 `Math.random / Date.now`（时间由页面注入）。
- **库存口径（写进注释与测试）**：W1 → W2 的区内移动**不计为出库**；跨仓转运有「在途」状态；**只有「出库发运」事件才扣减**，且同一事件 `id` 重复不重复扣减（幂等）。
- 样例里**不得出现真实客户 / 商户 / 地址 / 联系方式 / 真实车牌**；城市名可用（公开地理信息）。

## 隔离与文案红线
- 零 token、不请求网络、不读 Paperclip、不读任何真实订单 / 库存 / 车辆 / 视频；默认且唯一模式是 `demo`；无「强制完成 / 一键下发 / 控制设备」之类按钮（**本卡只读**）。
- 页面所有数据区块都要能看到「演示数据 · 模拟」；**不出现「已接入 / 实时同步 / 已验收」等暗示真实的措辞**；不涉及 DR 币与真实资金；不暗示现实资产权益（与第二十四节一致）。
- 性能与可访问性：首屏资源 ≤ 300 KB（不含字体回退）；`document.hidden` 暂停动画与定时刷新；演示刷新间隔 ≥ 5 秒；可键盘切换导航与筛选（Tab 顺序、`aria-label`）；深 / 浅主题对比清晰；宽屏（≥ 1600 px）完整布局、1280 px 紧凑、≤ 768 px 降级为纵向单列（可隐藏中央示意图的动画）。

## 测试与验收
- **数据测试（Node）**：确定性（同输入两次深度相等）；KPI 与底层数据一致（逐项重算断言）；分类托盘数之和 = 总库存；利用率 = 已用 / 总量；**不同计量单位不相加**（断言展示结构里单位分开）；事件幂等（重复 `id` 不重复扣减）；W1 → W2 区内移动不扣库存；不含禁用词 / 真实标识模式；静态检查（无 `fetch / XMLHttpRequest / Math.random / Date.now / innerHTML 拼外部数据 / eval`；`dr-console.html` 无外部域引用）。
- **浏览器（Playwright，页面聚焦）**：1920×1080、1280×720、390×844 各一张截图（深 / 浅主题各一组）；点击 W1 / W2 / W3 与左侧导航的筛选联动；作业流水筛选；`实时` 标签置灰；网络面板确认**除静态资源外无任何请求**；控制台 0 错误；隐藏页面后动画停止；同时打开主页面确认加载遮罩消失、无错误条（独立页面不得影响它）。
- 汇报「做到 / 没做到 / 未验证」，与磁盘一致，**每一项浏览器验证写出真实结果，没做的写「未验证」**。**不要自己重启服务。**
