## 补充缺陷（2026-10-22，董事会反馈：从仓配 / 办公区返回小镇地图总是有一层白色遮盖）——必须一并修
**根因（我已用启用后退缓存的 Chrome 复现）：** `navigateToPlace` 点击地点时给 `body` 设 `data-place-transition="true"`，`town.css` 让 `.map-shell` 变成 `opacity:.58`，并显示「正在进入…」提示；浏览器**后退**时 Chrome 从 bfcache 原样恢复页面，这个状态没有被清除，地图就一直发白、提示也残留。`town.js` 里没有 `pageshow` 处理。
**修复要求：**
1. 加 `window.addEventListener('pageshow', …)`：**无论 `event.persisted` 是否为真**，都清除 `document.body.dataset.placeTransition`、隐藏 `placeTooltip`、清掉悬停状态，并 `invalidate(true)` 重绘一次；
2. 跳转前设置的过渡状态只在**真正发生跳转**时存在：若 `location.assign` 因任何原因没有离开页面（被拦截 / 取消），`setTimeout` 之后用 `pagehide` 之外的兜底在 1.5 s 后自动清除；
3. 进入地点的过渡**不要用整页变白**：保持地图 `opacity ≥ .9`（只用轻微缩放 + 提示），即使状态被误留也不会出现白色遮盖；
4. **测试 / 验收：** 用 **启用后退缓存的 Chrome**（Playwright 需 `ignoreDefaultArgs: ['--disable-back-forward-cache']`）实测「点击办公室 → 进入 → 后退」与「点击 DR → 进入 → 后退」各一次：后退后 `placeTransition` 为空、`.map-shell` 不透明度为 1、提示隐藏；再测「返回小镇」链接（`place-bar`）进入的情况；并加一条回归测试固定这个行为。另外检查 `place-bar.js` 与其它页面（`command-view.html` 等）是否也有类似的「过渡状态在后退时残留」问题。
