【背景】董事会想看到团队「谁和谁在配合」：谁常交接、谁是评审瓶颈、哪些岗位几乎没有协作。灵感来自 AI Town 的角色关系，但**硬规则不变：只用真实协作事件；不推断情感，不生成「好感」「友情」；边上只显示数字；没有数据就写没有数据。** 这张图也是 T9（编制建议）的辅助依据，所以口径要写清楚、可核对。

## 1. 数据来源与「协作」的定义（先写进 `README.md` 和 `collab.mjs` 顶部注释）
数据只来自事件账本（`events/YYYY-MM-DD.jsonl`，字段 `id, at, kind, from, to, ref, text`）。对每个 **有向对 (from → to)**，统计窗口内的：
- **派单**：`kind = dispatch`（`from` 派给 `to`）；
- **交接 / 汇报**：`kind = report` 且 `to` 非空（`from` 向 `to` 汇报）；
- **互动发言**：`kind = speak` 且 `to` 非空且 `ref` 非空（与某个任务相关的、对某位同事说的话）——**休息区闲聊、八卦（无 `ref` 或 `lounge`）一律不算**；
- 事件里 `to` 为空的（庆祝、对全体发言）**不构成边**。
**账本目前没有的两类信号（评审通过 / 退回、阻塞解除）：** 本任务只允许在 `events-ledger.mjs` 里**补记两个字段**，且只能来自 `buildEvents` 已有的真实输出：如果 `buildEvents` 当前没有产生评审结果事件，**不要自己去解析活动流补，也不要推断**；在汇报里写「评审通过 / 退回暂无事件来源，本版图不含这两类」，并把它列为建议的后续任务。
- 窗口：最近 7 个上班日 / 14 个上班日 / 账本全部，可切换；账本时间不足时，页面写「数据自 yyyy-mm-dd 起，共 N 个上班日」，**少于 3 个上班日时在顶部显示「数据不足，仅供参考」**。
- 每条边带 `count`（总次数）和按类型的分项；**不做加权综合分、不排名「最佳搭档」**。

## 2. 派生指标（只输出数字，口径写在页面里）
- **度**：每个岗位的协作对象数（入 / 出分开）。
- **孤立岗位**：窗口内没有任何边的岗位（可能没被派活，也可能被绕开——页面不下结论，只列出）。
- **汇聚点**：入边次数最多的前 3 位（可能是评审或 Lead，只标「入边最多」，不评价好坏）。
- **一对一依赖**：某岗位 80% 以上的出边只指向同一位同事时标记（只提示，不下结论）。
- 以上全部写明「仅反映有记录的协作事件，不代表工作量或贡献」。

## 3. 界面（`collab-graph.js`，弹窗里的 2D 图）
- 入口：「治理」组里加「🕸 协作关系」，弹窗：左侧图，右侧岗位详情与指标，顶部窗口切换（7 / 14 / 全部）和类型筛选（派单 / 汇报 / 互动，可多选）。
- 图：25 个岗位按职能分组摆放（产品与设计 / 工程 / 质量与安全 / Dr.life+ / 运维 / 知识库 / 董事会，沿用 `office-layout.js` 的房间分组和颜色，不要另写一套分组）；边用粗细表示 `count`（对数缩放，最大宽度有上限）、箭头表示方向；悬停边显示「A → B：派单 x · 汇报 y · 互动 z」；点击岗位高亮其所有边并在右侧列出对象和次数；**没有边的岗位也要显示**（灰色），不能隐藏。
- 空状态：「账本里还没有足够的协作记录」；加载失败：显示错误并保留上次数据，不白屏。
- 无障碍与适配：键盘可聚焦岗位节点（Tab / Enter）；窄屏下图可缩放、右侧详情折到下方；`prefers-reduced-motion` 下无动画；所有文字用 `esc()`；**不展示 `text` 正文**（只展示数字和岗位名，避免泄露任务内容；`ref` 任务编号可显示）。
- 弹窗打开才请求数据、才绘制；关闭后释放；页面不得因此增加常驻开销。

## 4. 隐私与脱敏
- 接口和页面只输出岗位名、任务编号、次数，不输出事件正文；岗位显示名用现有 `names`。
- 大屏令牌设备**不得**访问该接口；局域网设备只读可看（过访问码）。
- 任务编号可能出现在标题里的敏感词不涉及（本版不输出标题）。

1. `import { buildCollab } from './collab.mjs'`（纯函数：输入账本事件数组 + 窗口 + 岗位列表，输出节点、边、指标、数据缺口说明）。
2. 新增只读 `GET /collab?window=7|14|all&kinds=dispatch,report,speak`：读事件账本（复用 T11 的读取函数，不另开文件解析），返回 `{window, from, to, workdays, nodes:[{id,name,group,inCount,outCount,degreeIn,degreeOut}], edges:[{from,to,count,dispatch,report,speak}], metrics:{isolated,hubs,oneToOne}, notes:[...]}`；参数非法返回 400；放在现有访问控制之后，**大屏令牌设备 403**（沿用 `API_PATHS`）。
3. 不改 `/state`；无 `act()` 改动。
4. 账本模块或本模块出错，只记日志并返回结构化错误，**不得影响 `/state`**。
