**本任务的例外规则：** 允许修改 `fun.js`（小橘的移动、规划、路径）、`cat-play.js`（只限与路径 / 区域判定相关的函数，T18 已有的逗猫行为不得退化）、`tests/cat-play.test.mjs`、新增 `tests/cat-pathing.test.mjs`、`README.md`。**不要改** `office-layout.js`（只读复用）、`director.js`、`pedestrian-traffic.js`、`app.js`（除非挂钩必须，改动 ≤ 5 行并写明）、`server.mjs` 和所有业务模块。纯前端，不需要重启服务。备份到 `office3d-backup-cat-pathing`（办公室目录没有 Git）。**不要与改 `app.js` 的其他任务同时进行。**

## 现象与根因（我已读过源码）
董事会反馈：**「小橘依然可以穿过桌椅的木板」**。`fun.js` 里猫的日常走动（不是 T18 的逗猫模式）这样写：
```js
const lanesLeft = [-4.4, 2.4, 8.3], lanesRight = [-2.0, 5.2, 10.6]       // 「过道」的 z 坐标，来自改版前的布局
const route = (from, to) => [ {from.x, lane(from)}, {x: 4.5, lane(from)}, {x: 4.5, lane(to)}, {to.x, lane(to)}, {to.x, to.z} ]
const ROAM = [{x:-12,z:2.4},{x:-3,z:-4.4},{x:2.5,z:8.3},{x:4.5,z:0},{x:9,z:5.2},{x:15,z:10.6},{x:-15,z:8.3},{x:0,z:2.4}]
```
布局改版（T7 方正化、Logo 区、前厅 / 广场、DR 广场）之后：南排房间 z 0…8、北排 z −12…−4，主横走道是 **z −4…0（通行线 z = −2.5 / −1.5）**，主竖走道 **x 0…4**；`z = 2.4` 和 `z = 5.2` 现在落在**质量室 / 运维室 / 计划室 / Dr.life+ 工作室里面**，`z = −4.4` 贴着北排房间的南墙，`x = 4.5` 已经不在走道中线上。猫沿这些直线走，**直接穿过玻璃墙、桌子和椅子**；它的 `cat.position += …` 没有任何墙体 / 家具碰撞检查。「趴在空闲同事桌上睡觉」（`deskTop`）的目的地 `(v.home.x + 0.9, v.home.z + 0.9)` 也没有按房间的门和通道走。

## 要求
1. **路径必须基于当前布局，不得再用写死的 lane / ROAM 坐标**：所有路点从 `office-layout.js` 派生（`CORRIDORS`、`CROSS_Z`、`CORRIDOR_X`、`FOYER_Z`、`ENTRANCE`、`OFFICE_ROOMS` 的门 `doors[]`、`LOUNGE_AREA`、`PLAZA`、`REGION_FOCUS`、`BOARD_DOOR` 等），并复用人物的路径函数（`officeExit` / `corridorPath` / `officeTrip` / `loungeTrip`）的**反向 / 同款路线**。猫是小动物，不占用人物的行人队列和让路机制，但**不得穿墙、不得穿家具、不得穿过人**（避让常量沿用 `PERSON_GAP`，人走过时猫停下或绕开，不要挤进人堆）。
2. **房间进出只走门和房内通道**：猫去「某位空闲同事桌上睡觉」时，路线 = 公共区域 → 该房间的门 → 沿**该同事离开座位时的反向路线**（即 `officeExit(v.home)` 的逆序）→ 走到桌边 → 再跳上桌（`deskTop`）。跳下来之后沿同一条路线退出房间，**不得从桌边直线走向任意目标**。猫在房间里时，记录它当前所在的「桌边锚点」（`C.deskHome`），出门前必须先沿该锚点的 `officeExit` 走出去。
3. **目的地合法性**：休息区、董事会门口、窗台、DR 广场、前厅等目的地都必须落在可走区域内（用 T18 的 `publicArea` 判定或房间内的通道判定）；**董事会门口** `(10.9, −3.6)`、**后窗台** `(−10, −12.3)` 要按当前布局重新核对（窗台在北排房间外墙外，是否可达要检查；不可达就换成合法的位置并写明理由）。
4. **随机溜达点**：`ROAM` 改为从公共区域（走廊、前厅、休息区、DR 广场）按布局派生的候选点里选，写成纯函数以便测试；候选点要通过「不在任何房间内部、不与摆件相交」的几何检查。
5. **跳上桌子的高度和位置**（`deskTop(x, z)`）不得让猫「陷进」桌面或悬空；坐在桌上时不得压住显示器 / 键盘的碰撞盒（用现有家具表判断桌面可用区域，不够就缩小到桌面空位）。
6. T18 的逗猫模式（追逐、拨球、停在门外）**行为不得退化**，两种模式共用同一套路径。
