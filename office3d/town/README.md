# 小镇生活家 · 经济引擎底座（T20）

纯虚拟的游戏经济底座：**DR 币（DRC）**，与真实金钱毫无关系，界面全部标注「虚拟 · 仅装饰」。

这一版只做 **纯函数 + 追加式账本 + 命令行试算**：
- 不接服务（不新增接口、不改 `server.mjs`）；
- 不接界面（不改 `ui.js` / `app.js`）；
- 不联网、不读 `town/` 之外的文件、不写账本到真实目录（账本目录由调用方传入，测试用临时目录）。

## 文件清单

| 文件 | 作用 |
|---|---|
| `town-engine.mjs` | 全部纯函数：工资条、考核、津贴、外快、发薪日历、通胀报告、金库与经济循环底座 |
| `town-config.json` | 所有数字放配置（档次月薪、津贴、考核权重、外快上限、经济循环参数），代码里不写死 |
| `town-ledger.mjs` | 追加式账本：哈希链防篡改、幂等、余额非负、守恒不变量、整批结算 |
| `town-cli.mjs` | 试算命令行：`node town/town-cli.mjs --month 2026-10 --input <json文件> [--json]` |
| `sample-2026-10.json` | 示例输入：含不满月（10 月 15–31 入职，17 个出勤日） |
| `sample-2026-11.json` | 示例输入：整月，含守门岗确认违规一例 |
| `README.md` | 本文档 |

测试在 `tests/town-engine.test.mjs` 与 `tests/town-ledger.test.mjs`。

## 单位与时区

- 货币 DRC，内部一律**整数「分」**（1 DR = 100 分），每个明细行 half-up 四舍五入到分后再求和；对外显示两位小数。
- 时区金边（UTC+7）；月份 `YYYY-MM`；统计窗口 = 自然月。
- 公司每周 7 天上班：应出勤天数 = 当月自然日数（28–31）；**计薪天数封顶 30**。

## 工资条（`buildPayslip`）

```
月薪 = 档次基数 × 考核系数 × 计薪天数/30
```

- 档次：T1 执行 336 / T2 专业 468 / T3 高级 636 / T4 负责人 840 / GA 守门岗A 795（廉洁津贴 80）/ GB 守门岗B 585（廉洁津贴 59）。
- 未登记岗位一律抛错「未登记岗位」，不发。
- 津贴：全勤奖 10（应出勤且实际出勤 = 自然日数）、餐补 0.5/天、交通补 7/月折算、工龄奖 2×⌊月/6⌋（封顶 11）。
- 考核系数：守门岗固定 1.0；数据不足（观察不足 7 天或考核任务不足 3 个或比率缺失）1.0；否则质量综合分 S 分段线性 0.8–1.5。
- 守门岗约束：有确认违规则廉洁津贴停发（明细写违规任务编号）；不领结果挂钩奖励（传入忽略并警告）；外快只允许知识贡献类。
- 娱乐型外快「矿洞探险」：确定性（`sha256(agent|date|dr-town-v1)` 首字节 mod 4，0–3 DR/日），只算 `eligible: true` 的日期，月度上限 `⌊档次基数×10%⌋`，超出截断并注明。

## 发薪日历

金边时间每月 **15 日 09:00** 起发**上一个自然月**；`payMonthFor(nowIso)` 返回应发月份（`YYYY-MM`），未到点返回 `null`。

## 通胀报告（`inflationReport`）

`sideIncome` = 娱乐型外快之和；`share = sideIncome / payroll`；超过 `8%` 阈值时 `exceeded: true`。

## 经济循环底座（第八节）

- **账户**：`wallet:<岗位名>`、`treasury`（金库）、`public`（公共项目，只进不出，永久回收）、`mint`（发行，只增）。
- **守恒不变量**：任意时刻 `Σwallet + treasury = 累计 mint − 累计 public`（整数分，零误差）；`verify()` 同时校验哈希链与守恒。
- **发放计划 `fundingPlan`**：金库先付，不足按产出锚定额度发行（`maxShare×payroll×clamp(outputIndex,0,1)`）；流通量超上限即暂停发行；**绝不为凑齐工资突破发行上限**（`fundingRatio < 1` 时 `paused`）。
- 生活成本（房租 32% + 水电 5%）、个人税（超 300 的 12%）、保管费（超本人 3 个月收入部分 × 费率）、金库溢出转公共项目（超 2 个月工资）、自适应保管费率（±0.5%/月，封顶 10% / 封底 1%）。
- `simulateMonths`：确定性月度模拟（无随机数），用于收敛/对照测试与后续界面预览。开办拨入 1 个月工资视同首次发行。

## 命令行试算

```text
node town/town-cli.mjs --month 2026-11 --input town/sample-2026-11.json
node town/town-cli.mjs --month 2026-10 --input town/sample-2026-10.json --json
```

只读输入文件（`buildPayslip` 的 input 数组），输出每人工资条明细与通胀报告；不写账本、不联网。

## 测试

```text
node --test tests/town-engine.test.mjs tests/town-ledger.test.mjs
node --test tests/*.test.mjs
node --check town/town-engine.mjs town/town-ledger.mjs town/town-cli.mjs
```

测试覆盖：第四节 A–I 全部算例（数字逐字断言）、配置真实读取、100 组固定种子随机输入的 half-up 与总和一致、
账本哈希链/幂等/余额非负/原子追加/守恒破坏定位/旧版兼容、第八节收敛（36 个月）与对照场景、产出锚定、
自适应保管费、金库溢出转公共，以及静态自检（扫描 `town/` 源文件不含禁用词与网络/进程调用）。

## 边界

- 本模块只使用「发放 / 余额 / 记账 / 消费」这类表述，不与任何真实账务流程混用；娱乐型外快统一叫「矿洞探险」，是确定性小额记账，不做任何计算型「挖」字行为。
- 不新增依赖；不读取/输出任何密钥、令牌、真实账号；不与真实薪资、编制决策、任务/审批流程有任何连接。
